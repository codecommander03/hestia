# Architecture decision records

One file per decision (NFR-MNT-6). Each one gives the context, the decision,
the alternatives that were rejected and why, and the consequences.

ADRs are never edited after they're accepted. If a decision changes, a new ADR
replaces the old one, and the old one's status becomes "Superseded by ADR NNNN".
